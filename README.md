# INF05028 — Guia de Estudos

Site estático, em português brasileiro, com um plano de estudo semana a semana para **Projeto e Análise de Algoritmos II (INF05028)**.

## Arquivo principal

- `index.html` — guia completo, autocontido, sem dependências externas.

## Base do conteúdo

O conteúdo foi sintetizado do relatório `Guia de Estudos de Algoritmos.md` presente no projeto e reorganizado conforme o cronograma de 2026/2. Provas, lista e plano de ensino disponíveis no projeto foram usados para conferir padrões de cobrança e evitar transformar regras históricas em regras universais do semestre atual.

## Visualização

Abra `index.html` diretamente no navegador. O arquivo também está preparado para publicação como site estático no GitHub Pages.

> Os arquivos-fonte acadêmicos não são redistribuídos neste repositório. O plano de ensino fornecido no projeto contém restrições de uso e distribuição de materiais didáticos; por isso, o site publica apenas uma síntese original para estudo.
